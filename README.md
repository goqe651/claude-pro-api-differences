## 先说结论：两个独立产品，账单各算各的

最容易踩的坑先排掉。Anthropic 官方帮助文档写得很清楚：**Pro 订阅不包含 API 使用权限**。你花在聊天订阅上的 20 美元，一分都不会抵扣 API 账单；反过来，只开 API 的人也完全不需要买 Pro。两套体系、两套计费，互不影响，也互不打折。

所以“API 和 Pro 有什么区别”的第一层答案是：它们不是同一产品的不同套餐，而是 Anthropic 面向两类人群的两个产品。Pro 卖给想在聊天界面里用 Claude 的个人用户，API 卖给想把 Claude 接进代码和应用的开发者。底层模型可以是同一批，但计费表、使用入口和默认设置完全是两套。

## 计费方式：固定月费和按量付费的账本

### Pro：一价全包，但只在部分地区提供

Pro 订阅美区定价 **20 美元/月**，支持本地货币的地区价格会有浮动，部分地区标价含税、部分在结账时另计；选择年付可以按折扣价一次付清。另外要注意，Pro 目前只在受支持的国家和地区开放，这后面还会牵出国内用户的支付难题。

### API：按 token 付费，用多少结多少

API 没有“月费”概念，账单按模型处理的 token 数累积、按日结算。以官方文档记录的价格为例：Haiku 每百万 tokens 输入 0.80 美元、输出 4 美元；Sonnet 输入 3 美元、输出 15 美元；Opus 4.5 输入 5 美元、输出 25 美元。不同模型价差很大，价格也随版本更新调整，动手前以官方价格页为准。

token 是模型计费的最小文本单位。按 Anthropic 的参考口径，1 百万 token 大约相当于 75 万个英文单词，听起来很多，但长对话、长文档和反复附带的上下文，烧起 token 来并不慢。

### 两个用量场景算笔账

假设条件先摆清楚：以下按 Sonnet 官方牌价估算，输入输出比例按常见对话粗算。

轻度用户，每天 10 条提问，每条约 1,000 输入加 800 输出 token，一个月下来输入 30 万、输出 24 万 tokens，合计大约 4.5 美元。这种用量买 Pro 纯属浪费。

重度用户，每天 80 条、每条 2,000 输入加 1,500 输出，一个月约 840 万 tokens，Sonnet 牌价下大约 68 美元，明显超过 Pro 的 20 美元；同样的用量换 Haiku 只需 18 美元上下。分界线大致就在“每天高频使用”这一档：轻中度用户按量付费更省，全天挂在 Claude 上的重度用户订阅更划算。

还有两个官方省钱开关值得记住：批量处理（Batch API）账单打五折；提示缓存（prompt caching）对重复上下文最高能省 90%。跑批量任务时，这两项对成本的影响比换模型还大。

## 用量限制：Pro 的两道闸门和 API 的余额逻辑

Pro 的限制分两层。第一层是会话限制：每 5 小时重置一次，能发多少条取决于消息长度、附件大小、当前对话长度和所用模型，官方没有给死数字，常见的参考口径是普通对话约 45 条每 5 小时，大约是 Free 版的 5 倍。第二层是每周上限：跨所有模型累计，每周在账户固定的固定时间重置，跟你何时开始订阅无关，重置时间可以在设置的用量页面查看。

临时爆量也有补救办法：用 limit reset 道具直接把 5 小时或每周限额拉满；或者在 Pro 之上开启 usage credits，超出额度后按量续用。觉得额度天生不够的，Max 5x（100 美元/月）和 Max 20x（200 美元/月）提供约 5 倍和 20 倍的用量上限。

API 这边简单得多：没有消息条数限制，余额够就能一直发。你可以在控制台设置预算上限防止超支，每一次请求都有用量明细。订阅端则看不到 token 级的消费记录，这也是两边在成本管理上的一个实际差别。

## 功能与入口：一个给界面，一个给钥匙

Pro 是成品。网页端、iOS、Android 和桌面客户端开箱即用，带历史会话侧边栏、Projects、文件拖拽上传，部分地区还有语音模式；高峰期优先接入，新功能和新模型通常先在订阅端上线，API 端一般一周左右跟上。

API 是钥匙。拿到 Key 之后，接 Cursor、Cline、Zed 这类编程工具，写脚本跑批量任务，搭聊天机器人、RAG 系统或产品后端，都是它的主场。代价是没有现成的聊天界面，控制台里的 playground 只够调试，非开发者拿到 Key 大概率不知道往哪填。

Claude Code 是个容易混淆的点：Pro 订阅里可以直接用终端版 Claude Code，不需要单独开 API；API 用户也能拿自己的 Key 跑 Claude Code，两条路都通。但订阅里的 Claude Code 权益不等于 API 权限，别把它当成“买了 Pro 就有 API”的证据。顺带一提，依赖 API Key 的第三方工具不会因为你有 Pro 就能用，只有少数像 Cline 这样的工具支持走 Pro 的 Claude Code 通道。

上下文窗口也有差异：订阅端单次对话上限 20 万 tokens（Team 版扩到 50 万），API 端部分模型提供 100 万 token 的长上下文选项，处理超长文档和整个代码库时差距会体现出来。

## 隐私和数据保留：默认设置完全不同

这一项最容易被忽略，但差别是结构性的。

> API 默认不使用用户数据训练模型，这是写在条款里的默认行为，不是可选项；操作日志只保留一个很短的窗口期，之后自动删除，也不保存聊天历史。
>
> Pro（包括 Free 和 Team）默认开启训练，需要自己在数据控制设置里手动关闭；聊天记录长期保存在账户里，账户一旦出问题，暴露的是全部历史对话。

要处理的内容比较敏感的话，API 的默认隐私姿态明显更稳。继续用 Pro 的话，至少把训练开关关掉。

## 怎么选：三种典型情况

**日常聊天、写作、查资料的个人用户**：选 Pro。20 美元换来界面、多端同步、高峰优先和省心，这个场景下 API 没有优势。

**开发者，或要把 Claude 接进产品的人**：直接开 API。按量计费适配用量波动，能做预算控制和逐请求的成本核算，批量任务折扣也只在 API 侧生效。

**两头都要的人**：不少开发者的做法是 Pro 管日常对话，API 账号管项目调用，两套账单互不干扰，取消哪边都不影响另一边。

## 常见问题

**买了 Pro 能直接调 API 吗？**

不能。官方明确 Pro 不含 API 权益，API 需要在开发者控制台单独开通、单独付费。

**Pro 用户调 API 有折扣吗？**

没有。API 价格对所有用户一视同仁，订阅状态不影响 API 账单。官方体系内的省钱手段是批量处理五折和提示缓存，跟订阅无关。

**取消 Pro 会影响 API 账号吗？**

不会。两套体系独立计费，取消订阅后 API 照常运行，反过来也一样。

**Pro 账号和 API 是同一个账号吗？**

可以用同一个 Anthropic 账号，但权益完全分开：Pro 的登录凭据本身不会生成 API Key，开 API 还是要走控制台的独立流程。用 API 也不要求先买 Pro。

**API 一定比 Pro 便宜吗？**

看用量。轻中度用户按量付费基本都在 20 美元以内；全天高频使用、尤其重度调用 Opus 的用户，API 花销可能反超订阅。token 构成比消息条数更影响账单，几百条 Haiku 快问快答，可能还没几条长 Opus 提示烧得多。
